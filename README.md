# Dataset-consumer-images (DCI)
The dataset is used to analyse the performance of the noise estimation methods.

The images were captured by the consumer mirrorless camera Canon EOS M100.

The measured by the Standard EMVA 1288 parameters are:  
* PRNU=0.0092±0.0003 rel.un.
* DSNU=0.191±0.005 DNs (in Digital Numbers).
* Camera gain value K=0.781±0.006 DN/e (in Digital Numbers to electrons).
* Dark temporal noise=2.479±0.004 DN (in Digital Numbers).

Dataset consists of
* 6 single images:
